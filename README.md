# homebrew-biomcp

Homebrew tap for [BioMCP](https://biomcp.org) — the Biomedical Model Context
Protocol CLI (`biomcp`).

## Install

```bash
brew tap genomoncology/biomcp
brew install biomcp
```

## Maintenance

`Formula/biomcp.rb` is updated automatically by the `homebrew-tap` job in the
[`genomoncology/biomcp`](https://github.com/genomoncology/biomcp) release
workflow each time a release is published. Do not edit the formula by hand.
